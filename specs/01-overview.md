# Project Overview: Job Application Tracker API

## Objective
Build a production-ready, secure RESTful API for tracking job applications using FastAPI and PostgreSQL.

## Tech Stack
- **Framework:** FastAPI (Python 3.10+)
- **Database:** PostgreSQL with SQLAlchemy & Alembic
- **Validation:** Pydantic v2
- **Auth:** JWT (python-jose) + Passlib (bcrypt)
- **Deployment:** Render
